# InternGuard Frontend — Cybersecurity SaaS React UI

The React + Vite + Tailwind CSS frontend interface for InternGuard.

## Features
- **SaaS Cyber Interface**: Dark slate background with glowing indicator badges, glassmorphic cards, and clean typography.
- **Interactive Analysis Studio**: Tabs for Text Message, Image Screenshot (OCR), and URL verification.
- **Demo Presets**: Instant 1-click loading for High Risk (86), Needs Verification (45), and Low Risk (10) scenarios for live hackathon judging.
- **Explainable Safety Reports**: Visual circular SVG risk gauge, point-by-point evidence breakdown, "WHY THIS MATTERS", and "WHAT YOU SHOULD DO" recommendations.
- **Community Warning Hub**: Search and file community reports regarding suspicious recruiters and companies.
- **Resilient Fallback Mode**: Works seamlessly online with the Express backend, or offline via local storage & calculation engines if APIs are unavailable.

## How to Run

1. Navigate to `frontend`:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start dev server:
   ```bash
   npm run dev
   ```

4. Open in browser: `http://localhost:3000`
